# web-demos

Standalone, dependency-free browser demos referenced from articles on
[jonnymatic.com](https://jonnymatic.com). Each demo lives in its own folder, has no build step,
and can be downloaded and run by opening its `index.html` directly in a browser.

## Demos

- [`mode7/`](mode7) — Mode7-style scanline perspective rendering in a `<canvas>`. See
  [the article](https://jonnymatic.com/blog/gamedev-mode7-html5/).
